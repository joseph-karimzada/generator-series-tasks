# ΣLab - Генератор Задач по Математическим Рядам

Веб-приложение для генерации настраиваемых практических задач по математическим рядам с детерминированным начальным числом и поддержкой нескольких языков.

## 🎯 Обзор

ΣLab - это образовательный инструмент, предназначенный для помощи студентам в практике различных типов задач по математическим рядам. Преподаватели могут генерировать согласованные наборы задач, используя начальные числа, в то время как студенты могут работать над различными типами рядов, включая геометрические прогрессии, телескопические ряды и полиномиальные дроби.

## ✨ Возможности

### Основной Функционал
- **Детерминированная Генерация**: Использование сида рандома для создания воспроизводимых наборов задач
- **Множество Типов Задач**:
  - Геометрические Прогрессии
  - Телескопические Ряды
  - Полиномиальные Дроби (с системой параметров для сложных математических объектов)
- **Настраиваемые Листы**: Выбор количества задач каждого типа
- **Поддержка Нескольких Языков**: Английский и русский с автоматическим определением
- **Сохранение Состояния**: Автоматическое сохранение конфигурации и сгенерированных задач в localStorage
- **Множество Режимов Просмотра**:
  - Режим Карточек: Интерактивные карточки с развернутыми деталями
  - Простой Режим: Чистый макет в стиле документа, идеальный для печати
- **Функция Экспорта**: Экспорт листов в формат Word (с ответами или без)

### Технические Возможности
- Профессиональный рендеринг LaTeX с использованием KaTeX
- Адаптивный дизайн (десктоп и мобильные устройства)
- Модульная архитектура с генерацией задач на основе навыков
- RESTful API бэкенд
- Генерация псевдослучайных чисел с начальным числом для воспроизводимости
- Точная дробная арифметика для точных ответов

## 🛠️ Технологический Стек

### Фронтенд
- **React** (v18+) - UI фреймворк
- **Vite** - Инструмент сборки и dev-сервер
- **KaTeX** - Рендеринг математики LaTeX
- **i18next** - Интернационализация
- **Axios** - HTTP клиент

### Бэкенд
- **Node.js** - Среда выполнения
- **Express** - Веб-фреймворк
- **Pandoc** - Конвертация документов (LaTeX в Word)

### Движок Генерации Задач
- Пользовательская система параметров, поддерживающая:
  - Числа
  - Дроби (точная арифметика)
  - Многочлены
  - Массивы и сложные объекты
- Генерация задач на основе шаблонов с JSON конфигурацией
- Система проверки ограничений
- Детерминированный RNG с использованием алгоритма PCG

## 🚀 Установка и Настройка

### Требования
- Node.js (v16+)
- npm или yarn
- Pandoc (для функции экспорта)

### Шаги Установки

1. **Клонировать репозиторий**
```bash
git clone https://github.com/joseph-karimzada/generator-series-tasks.git
cd generator-series-tasks
```

2. **Установить зависимости**
```bash
# Установить все зависимости workspace из корня
npm install

# Или установить по отдельности:
cd backend && npm install
cd ../frontend && npm install
cd ../task-engine && npm install
```

3. **Установить Pandoc** (для экспорта документов)
```bash
# Ubuntu/Debian
sudo apt-get install pandoc texlive-latex-base texlive-fonts-recommended

# macOS
brew install pandoc

# Windows
# Скачать с https://pandoc.org/installing.html
```

4. **Запустить серверы разработки**

```bash
# Терминал 1 - Бэкенд (из корня проекта)
node backend/src/server.js
# Запускается на http://localhost:3001

# Терминал 2 - Фронтенд
cd frontend
npm run dev
# Запускается на http://localhost:5173
```

5. **Открыть в браузере**
Перейти на `http://localhost:5173`

## 📖 Руководство Пользователя

### Генерация Задач

1. **Введите Сид Рандома**: Любая строка, определяющая случайную генерацию
2. **Выберите Типы Задач**: Используйте кнопки +/- для выбора количества каждого типа
3. **Нажмите "Сгенерировать Задачи"**: Создает ваш пользовательский лист
4. **Просмотр Результатов**: Переключайтесь между режимами карточек и простым режимом

### Экспорт Листов

1. Нажмите кнопку **Экспорт в Word**
2. Выберите:
   - **Без Ответов**: Только набор задач
   - **С Ответами**: Включает ответы на отдельной странице
3. Документ загружается как файл `.docx`

### Поддержка Нескольких Языков

- Нажмите **EN/RU** в заголовке для переключения языков
- Язык автоматически определяется по браузеру/часовому поясу
- Предпочтение сохраняется в localStorage

## 🎨 Конфигурация

### Добавление Новых Типов Задач

1. **Создать шаблон** в `task-engine/src/templates/`:
```json
{
  "name": "my-new-task",
  "params": {
    "a": { "type": "int", "min": 1, "max": 10 },
    "b": { "type": "int", "min": 1, "max": 10 }
  },
  "constraints": [
    { "code": "a < b", "params": ["a", "b"] }
  ],
  "latex": "\\displaystyle\\sum_{n=${a}}^{${b}} n",
  "answer": "((b - a + 1) * (a + b)) / 2"
}
```

2. **Зарегистрировать в TaskFactory**: Шаблоны автоматически загружаются из директории templates

3. **Добавить на фронтенд** в `src/config/taskTypes.js`

### Настройка Стилей

Редактируйте `frontend/src/App.css` - CSS переменные в начале:
```css
:root {
  --color-primary: #2563eb;
  --color-accent: #d97706;
  --font-display: 'Libre Baskerville', Georgia, serif;
  --font-body: 'IBM Plex Sans', sans-serif;
}
```

## 📝 Документация API

### POST `/api/generate`
Генерация задач на основе сида рандома и порядка.

**Запрос:**
```json
{
  "seed": "string",
  "order": ["task-type-1", "task-type-2", ...],
  "language": "en" | "ru"
}
```

**Ответ:**
```json
{
  "tasks": [
    {
      "type": "geometric-progression",
      "text": "Вычислите сумму...",
      "latex": "\\sum_{n=1}^{10} 2^n",
      "params": { "a": 2, "n": 10 },
      "answer": "2046"
    }
  ]
}
```

### POST `/api/export`
Экспорт листа в формат Word.

**Запрос:**
```json
{
  "tasks": [...],
  "seed": "string",
  "includeAnswers": boolean,
  "taskTypeLabels": {...},
  "language": "en" | "ru"
}
```

**Ответ:** Бинарный файл `.docx`
